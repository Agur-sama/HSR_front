# Тестовые фикстуры — ПЗ7, шахматная таблица пассажиропотоков

Источник: `ПЗ7_Расчет_набора_остановок_и_потребного_парка_ВСПС_v1.pdf`, «Основные принципы построения графика движения поездов на ВСМ». Это иллюстративный пример из теоретического раздела (5 станций А–Д), не привязан к конкретному варианту — в реальном использовании размер таблицы будет 2–4 станции по факту созданных в ПЗ1. Годится как фикстура для функции построения/суммирования шахматки любого размера.

## Матрица (симметричная, диагональ не используется)

|      | А    | Б    | В    | Г    | Д    |
|------|------|------|------|------|------|
| **А** | —    | 1087 | 2391 | 2956 | 2578 |
| **Б** | 1087 | —    | 2120 | 2130 | 2279 |
| **В** | 2391 | 2120 | —    | 696  | 2730 |
| **Г** | 2956 | 2130 | 696  | —    | 966  |
| **Д** | 2578 | 2279 | 2730 | 966  | —    |

Читается: «из Б до Г — 2130 пасс./сутки».

## Инвариант для теста

- Матрица симметрична: `matrix[i][j] === matrix[j][i]` для любых `i ≠ j`
- Диагональ заблокирована (не редактируется, не участвует в сумме)
- Общий пассажиропоток линии — сумма верхнего (или нижнего) треугольника матрицы, умноженная на 2 (т.к. симметрична), либо сумма всех ячеек без диагонали (эквивалентно)

## Ожидаемый результат

```json
{ "totalDailyFlow": 39866 }
```

Проверено: сумма всех 20 заполненных ячеек (без диагонали) = 39 866 пасс./сутки — совпадает с числом, явно указанным в методичке.
