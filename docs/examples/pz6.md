# Тестовые фикстуры — ПЗ6, расчёт стойл в депо

Источник: `ПЗ6_Расчет_потребного_количества_стойл_в_производственном_корпусе.pdf`, «Исходные данные» + «Пример проведения расчётов». Числа проверены напрямую по PDF.

## Формулы (каскад — каждая формула вычитает предыдущие)

```
S = 365 * 2 * l * N

P_R5 = S / L_R5
P_R4 = S / L_R4 - P_R5
P_R3 = S / L_R3 - (P_R5 + P_R4)
P_R2 = S / L_R2 - (P_R5 + P_R4 + P_R3)
P_R1 = S / L_R1 - (P_R5 + P_R4 + P_R3 + P_R2)

P_IS530 = S / L_IS530 - ΣP_R
P_IS520 = S / L_IS520 - (ΣP_R + P_IS530)
P_IS510 = S / L_IS510 - (ΣP_R + P_IS530 + P_IS520)

P_N = S / L_N - ΣP_(R,IS)
P_L = S / L_L - (ΣP_(R,IS) + P_N)

A_R  = Σ(P_Ri  * t_Ri  / (24*365)) * 1.2
A_IS = Σ(P_ISi * t_ISi / (24*365)) * 1.2
A_NL = (P_N*t_N/(24*365) + P_L*t_L/(24*365)) * 1.2
```

**Не хватает данных:** нормы пробега `L_R5…L_R1, L_IS530…L_IS510, L_N, L_L` и времена обслуживания `t_Ri, t_ISi, t_N, t_L` в explicit-виде в этом фрагменте методички не зафиксированы отдельной таблицей — они должны быть в разделе с нормативами (не путать с исходными данными варианта). Нужно досмотреть методичку на эту таблицу отдельно перед тем, как кодировать формулу как чёрный ящик — сейчас известны только промежуточные и финальные результаты для сверки теста, не сами нормативы.

## Входные данные примера (вариант 0)

```json
{ "l": 350, "N": 20 }
```

## Ожидаемый результат (вариант 0, из «Пример проведения расчётов»)

```json
{
  "revisions": { "R5": 0.68, "R4": 0.34, "R3": 0.34, "R2": 0.68, "R1": 2.04 },
  "inspections": { "IS530": 6.56, "IS520": 10.65, "IS510": 21.29 },
  "maintenance": { "N": 212.92, "L": 1022.00 },
  "stalls": {
    "revisions": { "R5": 0.11, "R4": 0.03, "R3": 0.03, "R2": 0.03, "R1": 0.07, "total": 1 },
    "inspections": { "IS530": 0.03, "IS520": 0.03, "IS510": 0.03, "total": 1 },
    "maintenance": { "N": 0.12, "L": 0.14, "total": 1 }
  },
  "totalStalls": 3
}
```

Обратите внимание: `total` в каждой группе — это уже округлённое до целого число стойл (округление вверх, судя по значениям — сумма нецелых 0,11+0,03+0,03+0,03+0,07=0,27 округляется до 1 стойла на группу как минимум). Логику округления стоит перепроверить отдельно — методичка не объясняет правило округления текстом, только показывает результат.
