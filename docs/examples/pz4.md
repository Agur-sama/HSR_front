# Тестовые фикстуры — ПЗ4, напряжение плеч питания

Источник: `ПЗ4_Системы_электроснабжения_на_ВСМ_v2_1.pdf`, «Пример проведения расчётов». Числа проверены напрямую по PDF, не пересказ.

`U_Н` — фиксированная константа для всех вариантов: **27,5 кВ**, не варьируется.

## Входные данные примера (вариант 0)

```json
{
  "S_KZ": 1000,
  "U_N": 27.5,
  "S_N": 48,
  "u_K": 10.5,
  "I_L": 300,
  "I_P": 500,
  "phi_L": 28,
  "phi_P": 33
}
```

## Формулы (в порядке расчёта, каждый шаг использует предыдущий)

```
x_C = U_N² / S_KZ
x_T = (u_K / 100) * (U_N² / S_N)

ΔU_L = I_L * (2*x_C + x_T*sin(phi_L)) - I_P * x_C * sin(60° - phi_P)
ΔU_P = I_P * (2*x_C + x_T*sin(phi_P)) + I_L * x_C * sin(60° + phi_L)

U_L = U_N - ΔU_L * 10⁻³
U_P = U_N - ΔU_P * 10⁻³
```

## Ожидаемый результат (округление методички)

```json
{
  "x_C": 0.756,
  "x_T": 1.654,
  "deltaU_L": 274,
  "deltaU_P": 1089,
  "U_L": 27.2,
  "U_P": 26.4
}
```

Единицы: `x_C`, `x_T` — Ом; `deltaU_L`, `deltaU_P` — В; `U_L`, `U_P` — кВ.

**Не проверено:** точность округления промежуточных шагов (методичка даёт только финальные значения из примера, не промежуточные с полной точностью) — при написании теста ориентироваться на совпадение финальных `U_L`/`U_P` с разумной погрешностью (например, ±0,1 кВ), не требовать байт-в-байт совпадения x_C/x_T.
