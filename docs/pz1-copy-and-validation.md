## Шаг — Карта трассы

**Заголовок шага:** Размещение станций и план трассы
**Цель (teal-callout):** Назначьте начально-конечные станции (А и Г) и не более двух промежуточных (Б, В), затем проложите линию ВСМ между ними.

**Режимы карты — одной строкой:** Просмотр / Станция / Линия трассы / Центр.

**Режим «Просмотр»**
- Пан/зум карты без создания и перетаскивания объектов. Дефолтный режим после `Esc`.

**Режим «Станция»**
- Подсказка в футере: Кликните по карте, чтобы поставить станцию. Перетащите поставленную, чтобы подвинуть.
- Пустое состояние: **Станции пока не назначены** / Кликните по карте, чтобы поставить первую станцию (А)
- Порядок назначения: А (конечная и начальная) → Г (конечная и начальная) → Б, В (промежуточные, опционально)
- Термин «обязательная» станция заменён на **«конечная и начальная»** во всех местах UI

**Режим «Линия трассы»**
- Подсказка в футере: Кликните, чтобы добавить точку линии. Ведите линию в обход водоёмов и возвышенностей.
- Пустое состояние: **Линия не проложена** / Добавьте точки, чтобы проложить трассу между станциями
- Каждый сегмент — поле **«Радиус между точками, м»** (по сути хранит стрелу прогиба, см. `pz-specs.md`), значение по умолчанию 0 (прямая вставка), удаление сегмента доступно

**Привязка станции к региону:** выпадающий список с поиском, справочник субъектов РФ статикой в бандле. Обязательное поле — используется на следующих шагах.

**`Esc`** переводит карту в режим «Просмотр» (не «Станция» — решение от 11.08 отменено заказчиком 26.08, финальное).

### Валидация

| Правило | Тип | Сообщение |
|---|---|---|
| Ровно 2 конечные и начальные станции (А, Г) | блокирует «Далее» | Назначьте обе конечные и начальные станции — А и Г |
| Промежуточных ≤ 2 | блокирует постановку | **Достигнут лимит промежуточных станций.** Можно назначить не более двух (Б и В). Удалите одну, чтобы поставить другую. |
| Название станции непустое и уникальное | блокирует «Далее» | Названия станций должны различаться — измените одно из них |
| Линия трассы ≥ 2 точек | блокирует «Далее» | Проложите линию трассы — нужно минимум две точки |
| Регион станции выбран | блокирует «Далее» | Выберите регион станции — понадобится для расчёта прогноза |
| Станция вне территории РФ | предупреждение | Станция находится за пределами России — проверьте, что это верно |
| Радиус между точками < 0 | блокирует ввод | Значение не может быть отрицательным |

**Важно:** лимит станций (2 + макс. 2) — жёсткий. Лимита на точки линии трассы и на сегменты — нет.

## Шаг — Время хода ВСМ

**Заголовок шага:** Время хода ВСМ
**Цель:** Задайте среднюю скорость на каждом перегоне. Итоговое время ВСМ рассчитывается автоматически в формате ЧЧ:ММ.

Карта на этом экране **не отображается**.

Таблица «Время хода ВСМ по перегонам» — столбцы: Перегон · Километровая отметка · Расстояние, км · Средняя скорость, км/ч (ввод) · Разгон, мин (2, нередактируемо) · Торможение, мин (1, нередактируемо) · Время, ЧЧ:ММ.

Блок «Итоговое время ВСМ»: Разгон всего · Торможение всего · Перегонов · Итого.

**Подсказка под итогом:** Чистое время ВСМ в прогнозе берётся отсюда. Существующее время ВСМ в модели остаётся 0, потому что линии ещё нет.

### Валидация

| Правило | Тип | Сообщение |
|---|---|---|
| Скорость > 0 | блокирует «Далее» | Скорость должна быть больше нуля |
| Скорость вне 50…400 км/ч | предупреждение | Скорость нетипична для этого вида транспорта — проверьте значение |

## Шаг — Характеристики регионов

**Заголовок шага:** Характеристики регионов
**Цель:** Заполните ВРП, население, зарплату и коэффициент влияния ВВП на пассажиропоток для регионов начальной и конечной станции.

Таблица «Характеристики регионов» — по каждому региону (не по корреспонденции; при совпадении региона у нескольких станций значения одни на регион, подставляются по ссылке): ВРП существующий/прогнозный (млн руб., ячейка пополам) · Численность населения существующая/прогнозная (тыс. чел., ячейка пополам) · Средняя заработная плата (руб./мес.) · **Коэффициент влияния ВВП на пассажиропоток** (безразм.; подпись — формулировка заказчика, расчёт по-прежнему региональный, переменная в коде `kGdpFlow`).

Отдельное поле (не по региону): **Прогнозируемый индуцированный спрос**, % — с подсказкой «i»:
> «Дополнительный пассажиропоток, который возникает вследствие запуска новой линии и не существовал бы при её отсутствии.»

**Существующие ВРП/население — ручной ввод студента** (данные Росстата), **не из варианта задания и не disabled**. Прогнозные — тоже ручной ввод, по заданию (динамика роста задаётся вариантом в методичке, но конкретные прогнозные числа вводит студент).

**Блок проверки (info-callout):** Для каждой корреспонденции берётся пара регионов её станций. Если несколько станций находятся в одном регионе, значения повторяются автоматически из одного блока.

### Валидация

| Правило | Тип | Сообщение |
|---|---|---|
| ВРП > 0 | блокирует | Значение должно быть больше нуля |
| Население > 0, целое | блокирует | Введите положительное целое число |
| Зарплата > 0 | блокирует | Значение должно быть больше нуля |
| Индуцированный спрос 0…100% | блокирует | Значение должно быть от 0 до 100% |
| `kGdpFlow` вне 0…2 | предупреждение | Значение нетипично — проверьте расчёт |

## Шаг — Время в пути

**Заголовок шага:** Время в пути
**Цель:** Заполните четыре составляющих реального времени в дороге для всех корреспонденций на одной странице.

Таблица на каждую корреспонденцию (заголовок — названия станций, не «А-Б»), 6 видов транспорта × ячейка пополам (Сущ. / Прогн.):

| Строка | ВСМ | Личное авто |
|---|---|---|
| Среднее время от центра города 1 до вокзала/автовокзала/аэропорта, ЧЧ:ММ | ввод | **0:00, заблокировано** |
| Среднее время ожидания отправления транспортного средства, ЧЧ:ММ | ввод | **0:00, заблокировано** |
| Чистое время поездки, ЧЧ:ММ | **из шага «Время хода ВСМ»**, только прогнозное | ввод |
| Среднее время от вокзала/аэропорта до центра города 2, ЧЧ:ММ | ввод | **0:00, заблокировано** |
| **ИТОГО** | сумма | сумма |

- Сокращение «ТС» пишется полностью — **«транспортное средство»**

### Валидация

## Шаг — Коэффициент дискомфорта

**Заголовок шага:** Коэффициент дискомфорта
**Цель:** Проверьте существующие и прогнозные коэффициенты дискомфорта по всем корреспонденциям.

**Одна таблица** (не две) на корреспонденцию — ячейка пополам (Сущ. / Прогн.), 9 строк критериев × 6 видов транспорта (ВСМ — только прогнозная колонка, существующей линии нет):

1. Индекс плотности пассажиров в салоне
2. Индекс уровня шума, вибрация, плавности хода, пересадки
3. Индекс качества работы климат-контроля, наличие неприятных запахов и пр.
4. Индекс объёма и качества дополнительных услуг, оказываемых пассажиру
5. Индекс технической безопасности транспортного средства (индекс аварийности), предсказуемость в пути
6. Индекс личной безопасности (охрана, безопасность, вероятность кражи)
7. Наличие свободных мест
8. Сложность приобретения билета
9. Коэффициент эластичности к уровню комфорта

Все 9 строк предзаполнены значениями по умолчанию (108 значений — см. `pz-specs.md`/`pz1-passenger-flow.md`), студент может отредактировать. **ИТОГО** — вычисляемое поле, среднее строк 1–8 (строка 9 в среднее не входит, см. `open-questions.md` — назначение строки 9 уточняется).

**Цветовая индикация ИТОГО:** градиент от зелёного (0, комфортно) к красному (1, дискомфортно). Цвет — не единственный носитель смысла: рядом всегда числовое значение.

### Валидация

| Правило | Тип | Сообщение |
|---|---|---|
| Значение 0…1 | блокирует | Коэффициент дискомфорта — это индекс от 0 до 1 |

## Шаг — Пассажиропоток и модель

**Заголовок шага:** Модель прогноза
**Цель:** Проверьте результат имитационной модели по всем корреспонденциям.

(В UI и PDF термин — **«имитационная модель»**, не «гравитационная» — последнее внутреннее название алгоритма, не показывается студенту.)

**Годовой пассажиропоток** — таблица на корреспонденцию: Вместимость ТС существующая/прогнозная (пасс.) · Заполняемость существующая/прогнозная (предзаполнено: самолёт 0,95, пригородный 0,7, дальнего следования 0,9, автобус 0,95, личный авто 1; ВСМ — 0,7 по умолчанию) · Рейсов/сутки · Поток, пасс./год.

**Вместимость ТС существующая для ВСМ — залочена на 0** (как частота/стоимость).

Формула: `A_год = 365 × рейсов_в_сутки × Вместимость × Заполняемость`.

**Если данных не хватает для расчёта модели** — блок со списком конкретных недостающих полей по имени (не общая фраза «заполните данные»): «Чтобы построить график имитационной модели, заполните недостающие поля: [список]».

**Диаграмма:** накопительная столбчатая «Существующие / Прогноз» по 6 видам транспорта (`recharts`), появляется, когда данные корреспонденции заполнены полностью.

## Чего НЕ писать

- Никакого канцелярита: «осуществите ввод данных», «необходимо произвести расчёт», «в целях определения»
- Не «Вы» с большой буквы
- Не восклицательные знаки в ошибках
- Не обвинять студента: «Вы ввели неверное значение» → «Значение должно быть от 0 до 1»

## Форматирование чисел

Разделение разрядов (неразрывный пробел) — на всех числовых полях, **кроме** коэффициента влияния ВВП (`kGdpFlow`) и индуцированного спроса (%) — это дроби/проценты, разделитель там неуместен. Форматирование только визуальное: при потере фокуса поля (`onBlur`) — `12000000` → `12 000 000`; при фокусе/редактировании поле показывает сырое число без разделителей. Проверить, нет ли уже готового компонента форматирования в `design-reference.html`, прежде чем писать новый.

Русская типографика — неразрывные пробелы после одно-двухбуквенных предлогов/союзов, см. `architecture.md`. Применяется ко всем текстам этого документа и к PDF-отчёту.
