## Шаг 1 — Карта трассы

**Заголовок шага:** Размещение станций и план трассы
**Цель (teal-callout):** Назначьте начально-конечные станции (А и Г) и не более двух промежуточных (Б, В), затем проложите линию ВСМ между ними.

**Режим «Станция»**
- Подсказка в футере: Кликните по карте, чтобы поставить станцию. Перетащите поставленную, чтобы подвинуть.
- Пустое состояние: **Станции пока не назначены** / Кликните по карте, чтобы поставить первую станцию (А)
- Порядок назначения: А (терминал) → Г (терминал) → Б, В (промежуточные, опционально)

**Режим «Линия трассы»**
- Подсказка в футере: Кликните, чтобы добавить точку линии. Ведите линию в обход водоёмов и возвышенностей.
- Пустое состояние: **Линия не проложена** / Добавьте точки, чтобы проложить трассу между станциями

### Валидация шага 1

| Правило | Тип | Сообщение |
|---|---|---|
| Ровно 2 терминальные станции (А, Г) | блокирует «Далее» | Назначьте обе начально-конечные станции — А и Г |
| Промежуточных ≤ 2 | блокирует постановку | **Достигнут лимит промежуточных станций.** Можно назначить не более двух (Б и В). Удалите одну, чтобы поставить другую. |
| Линия трассы ≥ 2 точек | блокирует «Далее» | Проложите линию трассы — нужно минимум две точки |
| Станция вне территории РФ | предупреждение (не блокирует) | Станция находится за пределами России — проверьте, что это верно |
| Две станции ближе 30 км друг к другу | предупреждение | Станции расположены очень близко (менее 30 км). Проверьте расстановку. |

**Важно:** лимит станций (2 + макс. 2) — жёсткий. Лимита на точки линии трассы НЕТ.

## Шаг 2 — Потребительские свойства

**Заголовок шага:** Потребительские свойства линии
**Цель:** Заполните характеристики поездки на каждом виде транспорта — они понадобятся для прогноза пассажиропотока.

Четыре таблицы, по всем видам транспорта (ВСМ, самолёт, пригородный поезд, поезд дальнего следования, автобус, личный автомобиль):

| Таблица | Единица | Валидация |
|---|---|---|
| Время в пути | ч | > 0, ≤ 48 |
| Коэффициент дискомфорта | индекс | 0 ≤ x ≤ 1 |
| Частота сообщения за сутки | рейсов | целое, ≥ 0 |
| Средняя стоимость проезда | руб. | > 0 |

**Сообщения:**
- Коэффициент дискомфорта вне 0..1: Коэффициент дискомфорта — это индекс от 0 до 1
- Пустое обязательное поле: Заполните это поле, чтобы продолжить
- Отрицательное значение: Значение не может быть отрицательным

## Шаг 3 — Матрица корреспонденций

**Заголовок шага:** Матрица корреспонденций
**Цель:** Укажите суточный пассажиропоток между каждой парой станций. Таблица построена по станциям, которые вы назначили на карте.

- Размер матрицы динамический: 2–4 станции (по факту назначенных).
- Диагональ заблокирована (откуда = куда), ввод невозможен.
- Ввод в ячейку зеркалит симметричную (А→Б = Б→А).

**Валидация:** целое ≥ 0. Все ячейки (кроме диагонали) обязательны.
**Живой итог:** Общий пассажиропоток линии: N пасс./сутки

## Шаг 4 — Прогноз пассажиропотока

**Заголовок шага:** Прогноз пассажиропотока
**Цель:** Рассчитайте прогнозируемый пассажиропоток по каждой корреспонденции с учётом роста ВРП и населения регионов.

Часть параметров подставляется из варианта (поля disabled, не редактируются): прирост ВРП, прирост населения, коэффициент чувствительности.

**Валидация:** все параметры > 0. ВРП и население — из варианта, не редактируются.
**Подсказка у disabled-полей:** Значение из вашего варианта — редактировать не нужно

## Шаг 5 — Технико-экономические показатели

**Заголовок шага:** Технико-экономические показатели
**Цель:** Сведите ключевые параметры линии. У капиталоёмких показателей рядом приведены справочные диапазоны — используйте их, чтобы прикинуть порядок величины.

13 полей (см. pz-specs.md). Поля со справочной подсказкой (`data-entry-hint`):

| № | Поле | Справочная подсказка |
|---|---|---|
| 9 | Затраты на строительство ВСМ, млрд руб. | Справочно: 1,5–2,5 млрд руб/км (простые условия) · 2,5–3,5 (средние) · 3,5–6,0 (сложные) |
| 10 | Затраты на приобретение подвижного состава, млрд руб. | Справочно: 3,5–4,5 млрд руб/ед. (8-вагонные составы) · 4,5–6,0 (12-вагонные) |
| 11 | Билетная выручка, млрд руб./год | Справочно: прирост пассажиропотока 5–7 % каждые 5 лет, с учётом прогнозируемой инфляции |

**Валидация:** значения > 0. Если значение выходит за справочный диапазон более чем вдвое — предупреждение (не блокирует): Значение сильно отличается от справочного диапазона. Проверьте расчёт.

## Чего НЕ писать

- Никакого канцелярита: «осуществите ввод данных», «необходимо произвести расчёт», «в целях определения»
- Не «Вы» с большой буквы
- Не восклицательные знаки в ошибках
- Не обвинять студента: «Вы ввели неверное значение» → «Значение должно быть от 0 до 1»
