# PDF-отчёт для преподавателя

**Ключевое решение:** отчёт выглядит как **обычная письменная работа**, распечатанная на бумаге — не как дашборд, не как презентация. Академический документ: титул, пронумерованные разделы, таблицы с рамками, формулы с подстановкой значений, словесные выводы.

**Важно:** `@react-pdf/renderer` **не использует** `design-reference.html` — у него свой движок стилей. Это отдельная дизайн-система. Не переносите CSS из веб-интерфейса в PDF.

---

## Типографика

| Элемент | Шрифт | Размер |
|---|---|---|
| Основной текст, таблицы | **Serif** (Times New Roman / PT Serif) | 11,5–12 pt |
| Заголовки разделов | Raleway ExtraBold | 14 pt |
| Шапка титула | Raleway ExtraBold | 11 pt |
| Колонтитул, номера страниц | Raleway | 9 pt |
| Подписи к рисункам/таблицам | Serif italic | 10 pt |

Почему serif: это письменная работа, а не презентация. Sans-serif выглядел бы как слайд.

## Цвет

**Минимальный.** Indigo `#3a288b` — только заголовки разделов и шапка титула. Никаких цветных заливок, никакого teal-фона. Таблицы — чёрные рамки, серая шапка `#f4f2fa`. Отчёт должен остаться читаемым на ч/б принтере.

## Структура (ПЗ1)

### Страница 1 — титул
- Шапка: ШКОЛА ВСМ · РУТ (МИИТ) / Детская проектно-исследовательская школа
- «Практическое задание № 1» + название задания
- Таблица: команда, название линии, вариант, дата выполнения
- Содержание с номерами страниц

### Страница 2 — исходные данные + карта
- **1. Исходные данные варианта** — таблица (регионы, Vmax, индуцированный спрос, год ввода)
- **2. План трассы и размещение станций**
  - **Карта — снимок PNG из MapLibre**, в рамке, с подписью «Рисунок 1 — План трассы ВСМ с размещением станций»
  - Под картой — **таблица станций** (станция, тип, координаты, расстояние от А). Данные должны быть и текстом, не только картинкой: препод может проверять числа, а не разглядывать пиксели.

### Страница 3 — расчёты
- **3. Матрица корреспонденций** — таблица с рамками + подпись «Таблица 1 — Суточный пассажиропоток между станциями, пасс./сут»
- **4. Прогноз пассажиропотока**
  - Формула в общем виде (в рамке, по центру)
  - Подстановка значений в строку: `F = 7 281,52 · 1,20 · 0,85 · 1,10 = 9 940,47 пасс./сут`
  - **Словесный вывод** — то, что препод реально проверяет

### Страница 4 — итоговые показатели
- **5. Технико-экономические показатели** — таблица из 13 строк

## Обязательные элементы на каждой странице (кроме титула)

- **Колонтитул сверху:** `Команда «Юнит-3» · ПЗ1 · ВСМ Владивосток — Хабаровск` — если препод распечатает 6 работ и они рассыплются, страницы можно собрать
- **Номер страницы** справа сверху

## Технические требования

- **Формат:** A4, поля 20 мм
- **Карта:** снимок PNG. MapLibre умеет отдавать canvas → PNG штатно (`map.getCanvas().toDataURL()`). Снимок делается **при завершении шага карты** и сохраняется в результат шага как `previewImage: string` (base64) — контракт для всех визуальных `kind`.
- **Формулы:** `@react-pdf/renderer` не рендерит KaTeX нативно. Для MVP — писать формулы обычным текстом с `<sub>` (как в макете, вполне читаемо). KaTeX→PNG — оптимизация на потом, не блокер (см. open-questions №13).
- **Числа:** разделитель разрядов — неразрывный пробел (7 281,52), десятичный разделитель — запятая (русская типографика).

## Комбинированный отчёт

`generateCombinedReport(bridge)` — вызывает `generatePzReport` для каждого заполненного `completed.pzN`, склеивает в один `<Document>`. Один шаблон, не два рендер-пути.
