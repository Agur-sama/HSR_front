## Цвета

**Утверждено заказчиком** (источник — `SCHOOLVSMCOLOURS.svg`, официальная палитра Школы ВСМ). Заменяет прежнюю палитру, засэмплированную из PDF методичек.

| Токен | HEX | Роль |
|---|---|---|
| `--primary` | `#003D84` | основной синий: заголовки, кнопки, линии, акценты |
| `--teal` | `#08A696` | акцент: «готово», подсказки, callout (не изменился) |
| `--accent-light` | `#B9D2FF` | светлый акцент: будущие/заблокированные элементы, disabled |
| `--bg-soft` | `#F3F7FF` | фон-подложка панелей и справочных блоков |
| `--ink` | `#232323` | основной текст |

Производные (границы, приглушённый текст, teal-семантика) — см. `:root` в `design-reference.html`, там единственный источник значений.

**История:** ранее использовалась палитра `#3a288b` / `#08A696`, засэмплированная из PDF методичек. Заменена по прямому указанию заказчика. Официальный брендбук РУТ (МИИТ) (`#1B365D` / `#0072CE`) по-прежнему НЕ используется — палитра относится к Школе ВСМ, не к головному вузу.

## Типографика

- Заголовки — **Raleway** (Medium/SemiBold/ExtraBold), Google Fonts
- Аудитория смотрит группой 5–6 человек с одного экрана — типографика крупнее, контраст выше, чем в типичном SaaS

## Визуальный вектор — Б, «Магистраль/табло»

Первый прототип в стиле типового SaaS-дашборда (скруглённые карточки, мягкие тени, пилюли-табы) заказчиком отклонён как «слишком иишный». Утверждённый язык:

- Прогресс модуля = горизонтальная линия-трасса со станциями-этапами (Интро → Теория → Задание → Итог), пунктир как шпалы, пройденный участок — заливка teal, станции — кружки (пустой контур = не пройдено, заливка = пройдено/текущая), текущая станция крупнее, с halo-обводкой
- Крупная моноширинная типографика для номеров шагов, в духе вокзального табло отправления (`03 из 04`, а не мелкий текст «Step 3 of 4»)
- Callout-блоки «Цель практического задания» — тёмный кружок-бейдж с номером на teal-подложке, воспроизводит визуальный язык методичек

## Не решено

- Тёмная тема — методички делают под печать/светлый фон. Нужен ли dark mode приложению вообще — отдельное решение продукта, не по умолчанию.
