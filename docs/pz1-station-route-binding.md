# ПЗ1. Связь станций и линии трассы

В текущей модели станции и линия трассы хранятся независимо.

Станция задаёт точку размещения начально-конечной или промежуточной станции. Линия трассы задаётся отдельным массивом вершин маршрута. Если студент двигает станцию, общая длина трассы сама по себе не меняется, потому что маршрут состоит не из станций, а из точек линии.

Расстояния между соседними станциями считаются вдоль отображаемой линии трассы: для каждой станции ищется ближайшая точка линии, затем берётся разница километровых отметок. Поэтому изменение точек линии меняет длины участков и общее расстояние, а изменение станции может изменить только привязку к ближайшей точке линии.

Это сделано осознанно: студент сначала ставит станции, затем отдельно трассирует линию ВСМ с обходом водоёмов, рельефа и других ограничений.
